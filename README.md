# AI Study Helper

A simple AI-powered web app that helps students study. Paste any text, pick a mode, and the AI will explain it simply, summarize it, or create a quiz from it.

Built as the Module 5 mini project for the Codomax Digital Solutions internship.

## Features

- **Explain it simply**: breaks down any topic in beginner-friendly words
- **Summarize**: turns notes into 5 short bullet points
- **Quiz mode**: generates a 5-question multiple-choice quiz with answers
- Clean, responsive interface

## Tech Stack

- HTML, CSS, JavaScript
- Groq API running OpenAI's open-weight model `gpt-oss-120b`

## How to Run

1. Get a free API key from [console.groq.com/keys](https://console.groq.com/keys)
2. Open `index.html` in a browser (or run it on StackBlitz)
3. Paste your API key into the key box (it is stored only in your browser, never in the code)
4. Paste some text, choose a mode, and click **Generate**
